# Story 14 - 릴리스 보안 기준선 강화

## 목표

릴리스 전 정적·동적 보안 게이트를 추가하고, 브라우저와 게시물 HTML 경계의 고위험 XSS 노출을 제거한다.

## 완료 기준

- 수동 작성, 리비전 복원, 레거시 게시물 응답에서 허용 목록 기반 HTML 정화
- 관리자 Markdown 미리보기에서 임의 HTML 실행 차단
- Next.js 보안 헤더와 환경별 정확한 API `connect-src` 적용
- 의존성 감사, 비밀 탐지, 파일/컨테이너 취약점 검사, CodeQL CI 추가
- 전체 품질 게이트, 보안 감사, 독립 코드 리뷰 및 검증 승인

## 범위 밖

실서비스 배포, 운영 비밀 입력, 인프라 생성, 영구 데이터 변경은 수행하지 않는다.
