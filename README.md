# GTU Blog

개인 사용자를 위한 자동 정보 수집·검증·게시 블로그입니다. Spring Boot가 도메인과 게시 정책을 소유하고, Next.js가 공개 블로그와 관리자 UI를 제공하며, 격리된 생성 워커가 공급자 중립적인 콘텐츠 생성 작업을 수행합니다.

현재 구현 기준은 다음 문서에 정의되어 있습니다.

- 제품 요구사항: `.omx/specs/deep-interview-automated-content-blog.md`
- 승인된 구현 계획: `.omx/plans/prd-automated-content-blog.md`
- 릴리스 테스트 계약: `.omx/plans/test-spec-automated-content-blog.md`
- 에이전트 운영 규칙: `AGENTS.md`

개발은 `prototype` 통합 브랜치에서 story 브랜치를 분기해 진행합니다.
